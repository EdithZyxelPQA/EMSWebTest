# EMS1-4495_3481 clearAlarm

## Objective

Verify that Map/Device Clear Alarm clears the current alarm list and that the device tree icon matches the alarm severity that exists after EMS refreshes.

## Test Data

- EMS URL and account: `environment_parameter.json`
- DUT: `ZYXEL_DUT.<cmdopt>`

## Steps

1. Open Map and select the DUT.
2. Click the Clear Alarm icon and confirm the EMS message.
3. Verify that the device Alarm Status `All` count becomes `0` immediately after Clear Alarm.
4. Wait 150 seconds so EMS can receive any alarm that is regenerated by a condition still present on the DUT.
5. Click Refresh.
6. Read the current Critical, Major, Minor, and Info counts from the device Alarm Status panel once.
7. Determine the expected tree icon from the highest current severity:
   - Critical greater than 0: `icon-dev-5`
   - Otherwise, Major greater than 0: `icon-dev-4`
   - Otherwise, Minor greater than 0: `icon-dev-3`
   - Otherwise, Info greater than 0: `icon-dev-2`
   - All severity counts equal 0: `icon-dev-1`
8. Verify that the DUT tree icon class matches the expected class.

## Expected Result

- The Alarm Status count is `0` immediately after Clear Alarm.
- If no alarm is regenerated during the 150-second wait, the tree icon is `icon-dev-1`.
- If an alarm is regenerated, the tree icon matches its current highest severity instead of being incorrectly required to remain `icon-dev-1`.
